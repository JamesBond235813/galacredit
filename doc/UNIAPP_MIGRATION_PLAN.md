# GalaCredit UniApp 三端统一迁移计划

## 已确认的目标

- `frontend_h5` 当前页面是唯一视觉与交互基准。
- H5、Android、iOS 最终只保留 `frontend_uniapp` 一套业务前端源码。
- Android/iOS 原生代码只保留系统能力桥接：权限、短信（仅内部 Android）、联系人、定位、图片选择、WebView 生命周期等。
- 迁移完成前保留 `frontend_h5` 作为只读基准，禁止继续把它作为线上运行入口之外的独立业务分支扩展。

## 迁移顺序

1. 登录、验证码、协议授权和品牌壳。
2. Layout、首页、底部导航、订单、账户。
3. 申请、身份认证、OCR、审核、定位和风险页。
4. 账单、提现、渠道、客服、密码、协议页。
5. 接口契约、错误提示、加载态、空态、弹窗和返回行为逐页回归。
6. 通过 H5、Android app-plus、iOS 构建与真机检查后，删除已迁移且不再引用的旧 H5 页面和依赖。

## 平台实现边界

- 页面结构、文案、颜色、间距、表单状态和业务请求统一使用 UniApp Vue 页面。
- 使用 `#ifdef H5`、`#ifdef APP-PLUS` 或平台工具函数处理平台差异，不复制整页。
- 原生桥只返回结构化结果，不承载页面布局和业务流程。
- 未完成逐页对齐前，不宣称三端已经统一，也不删除 `frontend_h5` 基准。
