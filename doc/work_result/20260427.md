## 修改说明（做了什么、为什么）
- 目标：将 `frontend_admin` 对 `api/admin/stats` 的高频轮询改为 WebSocket 实时推送，减少重复 HTTP 请求并实现即时状态感知。
- 后端新增后台统计 WS 通道：`/api/admin/ws/stats`，鉴权后每 5 秒推送一次 `admin_stats`。
- 前端 `Layout` 侧边栏角标改为优先消费 WS 消息，保留首次 HTTP 同步作为首屏兜底，断线自动重连（3 秒）。
- Vite 代理开启 `ws: true`，确保本地开发环境可通过 `/api` 代理 WebSocket。
- 联调中发现 WS 握手失败根因是运行环境缺少 `websockets/wsproto`；按最小改动补充 `backend/requirements.txt` 的 `websockets==12.0`。
