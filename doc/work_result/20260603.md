## 修改说明

- 修复管理 Web 端生产环境仍可能白屏的问题。
- 原因是发布后浏览器可能仍缓存旧入口 JS，旧入口在预加载已删除的异步 CSS/JS hash 资源时会触发 `vite:preloadError`，导致页面停留在空白状态。
- 在前端入口增加 `vite:preloadError` 监听，遇到资源预加载失败时阻止默认白屏错误，并在 10 秒窗口内最多自动刷新一次以拉取最新入口。
- 调整本次生产发布方式为“只覆盖不删除”，保留生产目录中的旧 hash 静态资源，兼容已经打开后台或缓存旧入口的浏览器。
