## 修改后的配置

生产配置文件：`/etc/nginx/conf.d/xhbadmin.juxin.pro.conf`

```nginx
location ^~ /assets/ {
    gzip_static on;
    add_header Cache-Control "public, max-age=31536000, immutable" always;
    try_files $uri =404;
}
```
