- 服务器资源检查正常：CPU 负载低、磁盘空间充足，`nginx` 与 `xiaohebao-backend.service` 均为 `active`。

- 确认生产 Nginx 对 `xhbadmin.juxin.pro` 的 `location /` 给所有静态资源设置了 `no-cache`，且没有单独 `/assets/` 规则，导致哈希静态资源不能长期缓存，也未使用已有 `.gz` 预压缩文件。
- 按最小改动修改腾讯云生产 Nginx：仅新增 `location ^~ /assets/`，启用 `gzip_static on`，并将哈希资源缓存策略设置为 `public, max-age=31536000, immutable`；`index.html` 继续保持禁缓存，避免前端入口更新不生效。

## 修改后的配置

生产配置文件：`/etc/nginx/conf.d/xhbadmin.juxin.pro.conf`

```nginx
location ^~ /assets/ {
    gzip_static on;
    add_header Cache-Control "public, max-age=31536000, immutable" always;
    try_files $uri =404;
}
```

生产备份目录：`/opt/xiaohebao/backups/xhbadmin-nginx-assets-cache-20260526103231`
