## 1. 修改说明（做了什么、为什么）
- 目标：按 AGENTS.md 强制要求，将 `backend` 内同步数据库访问彻底移除，统一为 `AsyncSession` 直接访问，避免“同步访问再包一层异步”。
- 范围：路由层、依赖层、服务层、调度器、初始化脚本、数据脚本。
- 原因：满足项目异步技术栈强约束，消除 `Session/db.query/run_sync` 同步路径，避免 event loop 阻塞风险。

### 关键改造摘要
- 全面替换：`db.query(...)` -> `await db.execute(select(...))`
- 删除同步入口：`run_sync(...)`、同步 `Session` 路径
- 服务函数统一异步：
  - 审计日志：`log_user_event_async`
  - 订单分配：`assign_*_async`
  - 账务台账：`ensure_installment_records_async`、`register_repayment_async`、`register_reduction_async`
  - 风控查询：`get_user_for_risk_report_async`、`get_or_create_risk_report_async`
- 调度器改为异步 session 执行
- 初始化/种子脚本改为异步 session 执行
