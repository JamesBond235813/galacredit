# 任务完成检查（按最新 AGENTS.md）

## 强制测试要求
1. 所有代码修改后必须编写并执行：
- 单元测试
- 集成测试（涉及模块交互时）

2. 覆盖要求
- 核心逻辑覆盖
- 边界条件覆盖
- 测试可重复执行

3. 执行要求
- 所有测试必须执行且通过。
- 若改动后端：必须启动后端进行测试。
- 若改动前端：必须同时启动后端与前端进行测试。
- 后端启动命令：在 `backend/` 下执行 `python -m app.main`。
- 涉及登录动作的测试必须串行执行。

## 建议附加检查
- `git status` 确认改动范围。
- `git diff` 自查无关改动。
- 修改代码时先检查是否违反 AGENTS.md 的异步/异常/响应规范。
